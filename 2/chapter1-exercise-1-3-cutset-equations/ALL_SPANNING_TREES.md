# ภาคผนวก A — รายชื่อ spanning tree ทั้งหมด

กราฟในข้อพิเศษมี spanning tree ทั้งหมด **139 ชุด**. แต่ละชุดด้านล่างเป็นเซตกิ่ง 5 กิ่ง (เพราะ $n-1=5$) ที่ต่อปมครบทั้ง 6 ปมและไม่มีวงรอบ โดยทิศของลูกศรไม่มีผลต่อการเป็น tree.
