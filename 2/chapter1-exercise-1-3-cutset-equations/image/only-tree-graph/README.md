# `only-tree-graph` — Clean spanning tree images

This directory contains the best-practice visual form of each spanning tree for the 6-node, 11-branch graph: only the **5 tree edges** are shown, with no links, no labels, and no titles. The same graph topology is used as the full problem diagram in the parent `image/` directory, but these files isolate each tree so the structure is clear.

## File naming

- `tree-NNN.svg` / `tree-NNN.png` — NNN matches the numbering in [ALL_SPANNING_TREES.md](../ALL_SPANNING_TREES.md)

## What the image shows

- A single spanning tree of the 6-node, 11-branch directed graph (the same graph used in the problem image folder)
- Nodes are fixed positions in two columns: left A, B, C; right D, E, F
- Only the 5 edges belonging to the tree are drawn; link edges are omitted
- Edge direction is preserved from the original directed graph and shown by an arrow at the **middle** of each edge
- Parallel branches (1/3 for A–B, 2/4 for B–C) use smooth cubic Bezier curves on opposite sides

## Design

- Node radius 6px, filled dark blue with a subtle inner highlight
- Tree edges drawn as solid lines with uniform 4px stroke
- Edges start/end exactly at the node boundary for seamless joints
- Arrowheads are centered on the middle of each edge, pointing along the edge direction
- Arrowheads are white with dark outline to contrast clearly with both dark edges and dark nodes
- Clean slate color palette on off-white background

## Branch labels

- Each tree edge is labeled with its branch number (1–12, excluding 11), matching the numbering in [ALL_SPANNING_TREES.md](../ALL_SPANNING_TREES.md) and `image/manifest.csv`
- Labels are placed near the middle of each edge, offset slightly to the left of the edge direction
- Each label is shown as a small white badge with a dark border so it is readable over both the edge and the background

### Why this labeling style

- **Position at the midpoint**: keeps the label away from nodes and clearly associates it with one edge only
- **Offset to one side**: avoids overlapping the arrow and the edge line; a consistent side (left of the directed edge) makes parallel pairs easy to distinguish
- **Small badge with border**: a white background (or a subtle padding box) makes the number readable whether it sits on a dark edge or a light background
- **No labels on link edges**: this is the `only-tree-graph` view, so only the five tree edges are shown and labeled

## Source and generation

- These trees are derived from the full graph in the parent `image/` directory (the same 6-node, 11-branch directed graph used in the problem statement)
- They are generated by `gen_tree_images_v5.py` from the branch manifest, with one image per row of [ALL_SPANNING_TREES.md](../ALL_SPANNING_TREES.md)
- The output is intentionally minimal so the tree itself is the only focus
