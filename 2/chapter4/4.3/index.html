1. โจทย์และสิ่งที่ต้องหา

[4.3] พิจารณาวงจรข่ายความต้านทานไฟฟ้าในรูปที่ 4บ.3(ก) และกำหนดให้แหล่งกำเนิดแรงดันอิสระ ต่ออนุกรมกับตัวต้านทาน R1 ตั้งอยู่บนกิ่งที่ 2 และแหล่งกำเนิดกระแสอิสระต่อขนานกับผลอนุกรม ของตัวต้านทาน R2 และ R3 ตั้งอยู่บนกิ่งที่ 1 ดังที่แสดงทรีของวงจรข่ายไว้ในรูปที่ 4บ.3(ข) ถ้ากำหนด j1 เป็นกระแสวงรอบ แล้วจงเขียนสมการรอบและจงคำนวณหาค่าของแรงดันกิ่งและกระแสกิ่ง

ข้อตกลงเครื่องหมายที่ใช้ตลอดเฉลย

ลูกศรบนกิ่งบอกทิศของกระแสกิ่ง และวางขั้ว + ของแรงดันกิ่งไว้ที่ หางลูกศร (associated reference direction) ทำให้ตัวต้านทานเป็นไปตาม v = Ri โดยตรง ผลที่ตามมาคือ vk = v(o) − v(a) สำหรับทั้งสองกิ่งในโจทย์นี้

2. คำตอบโดยสรุป

ให้ RT ≡ R1 + R2 + R3

(R1+R2+R3) j1  =  (R2+R3) is − vs
j1 = (R2+R3) is − vsR1+R2+R3

กระแสกิ่ง

i1 = +j1 = (R2+R3) is − vsRT
i2 = −j1 = vs − (R2+R3) isRT

แรงดันกิ่ง

v1 = v2 = − (R2+R3)(vs + R1is)RT

เครื่องหมายลบมาจากการวางขั้ว + ไว้ที่ปม o ถ้าอ่านเป็นแรงดันของปม a จะได้ค่าบวก: v(a) = +(R2+R3)(vs+R1is)/RT

3. วิเคราะห์รูปที่ 4บ.3(ก)

จุดตำแหน่งดีกรีสถานะ
aปมกลางบน — จุดร่วมของ R₁, iₛ, R₂3ปมจริง
oรางล่างทั้งเส้น — จุดร่วมของ vₛ, iₛ, R₃3ปมจริง เลือกเป็นปมอ้างอิง
cยอดเสาซ้าย — ระหว่าง vₛ กับ R₁2ยุบได้ (จุดต่ออนุกรม)
dมุมขวาบน — ระหว่าง R₂ กับ R₃2ยุบได้ (จุดต่ออนุกรม)

หลักการที่ใช้

ปมที่มีดีกรี 2 ไม่ให้สมการ KCL ที่เป็นอิสระเพิ่ม (กระแสเข้าเท่ากับกระแสออกโดยอัตโนมัติ) จึงยุบรวมองค์ประกอบสองตัวที่ต่ออยู่ให้เป็นกิ่งประกอบเดียวได้โดยไม่เปลี่ยนพฤติกรรมของวงจร

ระวัง: ที่ปม d ไม่มีทางแยก ดังนั้น R2 กับ R3 ต่อ อนุกรม กัน ความต้านทานของทางเดินนี้คือ R2+R3 ไม่ใช่ R2∥R3

4. ยุบเป็นกิ่งประกอบ 2 กิ่ง

กิ่งองค์ประกอบภายในรูปแบบเชื่อมปม
กิ่งที่ 2vs อนุกรม R1รูปทีวินินo → a
กิ่งที่ 1is ขนาน (R2 อนุกรม R3)รูปนอร์ตันo → a

ประโยชน์ของกิ่งประกอบคือ ย้ายความซับซ้อนไปไว้ในสมการเฉพาะกิ่ง แทนที่จะไปเพิ่มจำนวนสมการ ที่ต้องแก้ — กราฟที่ได้เล็กที่สุดเท่าที่จะเป็นไปได้

5. วิเคราะห์รูปที่ 4บ.3(ข)

สิ่งที่เห็นในภาพความหมาย
จุดทึบ 2 จุดปม 2 ปม ⇒ n = 2 (จุดบนคือปม a, จุดล่างคือปม o)
เส้นทึบหนาสีดำ เลข 2กิ่งที่ 2 เป็น ทวิก (twig) — อยู่ในทรี
เส้นบางสีแดง เลข 1กิ่งที่ 1 เป็น ลิงก์ (link) — อยู่นอกทรี
หัวลูกศรกลางเส้นทั้งสองชี้ขึ้นทิศอ้างอิงของกระแสกิ่งทั้งสองคือ o → a
หัวลูกศรบนวงประอยู่ด้านซ้ายและชี้ลงj1 หมุน ทวนเข็มนาฬิกา

ตรวจความสอดคล้อง

j1 ทวนเข็มนาฬิกา ⇒ ด้านขวาของวงรอบวิ่งขึ้น ซึ่งตรงกับทิศของกิ่งที่ 1 (ลิงก์) พอดี เป็นไปตามกฎที่ว่า ทิศของกระแสวงรอบต้องยึดตามทิศของลิงก์เสมอ ขณะที่ด้านซ้ายวิ่งลง ซึ่งสวนทางกับกิ่งที่ 2

การนับทางโทโปโลยี

n = 2 ,   b = 2 ,   ทวิก = n − 1 = 1 ,   ลิงก์ = l = b − n + 1 = 1

จำนวนสมการรอบอิสระ = จำนวนลิงก์ = 1 สมการ ⇒ ทั้งวงจรมีตัวแปรอิสระตัวเดียวคือ j1

6. สมการเฉพาะกิ่ง (branch v–i relation)

ขั้นนี้เป็นจุดเดียวที่ค่า R, vs, is เข้ามาในระบบสมการ

กิ่งที่ 2 — รูปทีวินิน

เดินจากปม o ขึ้นไปปม a: ผ่านแหล่งจ่ายจากขั้ว − ไป + ⇒ ศักย์เพิ่ม vs แล้วตกคร่อม R1 ⇒ ศักย์ลด R1i2

v(a) − v(o) = vs − R1 i2
v2 = R1 i2 − vs

กิ่งที่ 1 — รูปนอร์ตัน

กระแสของกิ่งแยกสองทาง: i1 = is + iR ส่วนที่ผ่าน R2, R3 คือ iR = i1 − is

v(o) − v(a) = (R2+R3) iR
v1 = (R2+R3)(i1 − is)

กับดักข้อใหญ่ที่สุดของโจทย์นี้

อย่าเขียน v1 = (R2+R3) i1 เพราะกระแสของแหล่งจ่าย is ไม่ได้ไหลผ่านตัวต้านทาน ต้องหักออกก่อนเสมอ

8. ตั้งสมการรอบแล้วแก้

  1. เดินรอบวงรอบตามทิศ j₁ — ผ่านกิ่ง 1 ตามทิศได้ +v1 ผ่านกิ่ง 2 สวนทิศได้ −v2
    (+1)v1 + (−1)v2 = 0
  2. แทนสมการเฉพาะกิ่ง
    (R2+R3)(i1 − is) − (R1 i2 − vs) = 0
  3. แทนการแปลงกระแส i1=j1, i2=−j1
    (R2+R3)(j1 − is) + R1 j1 + vs = 0
  4. รวมพจน์ที่มี j₁ — ได้สมการรอบ
    (R1+R2+R3) j1 = (R2+R3) is − vs

9. คำตอบแรงดันกิ่งและกระแสกิ่ง

หา v₂ จากกิ่งที่ 2

v2 = R1i2 − vs = R1vs − R1(R2+R3)is − RTvsRT = − (R2+R3)(vs+R1is)RT

ตรวจซ้ำโดยอิสระจากกิ่งที่ 1

v1 = (R2+R3)(j1 − is) = (R2+R3)· −R1is − vsRT = − (R2+R3)(vs+R1is)RT

สองทางให้ผลตรงกัน และสอดคล้องกับ v1 − v2 = 0 ที่ได้จาก KVL ✓

ปริมาณระดับองค์ประกอบ

ปริมาณนิพจน์ทิศ / ขั้ว
กระแสผ่าน R₁ และ vₛi2 = [vs − (R2+R3)is] / RTทิศ o → a
กระแสผ่าน R₂, R₃iR = −(vs + R1is) / RTทิศ o → a (ค่าลบ ⇒ ไหลจริงจาก a → o)
แรงดันคร่อม R₂R2(vs+R1is) / RT+ ที่ด้านปม a
แรงดันคร่อม R₃R3(vs+R1is) / RT+ ที่ด้านบน
แรงดันคร่อมแหล่งกระแสv(a) = (R2+R3)(vs+R1is) / RT+ ที่ด้านบน

10. ตรวจคำตอบ 4 ทาง

10.1 ตรวจด้วยวิธีปม

เขียน KCL ที่ปม a จากรูป (ก) โดยตรง โดยให้ v(o)=0

10.2 ตรวจด้วยกรณีพิเศษ

11. กับดักที่ทำให้ตอบผิดบ่อย

#กับดักผลที่เกิดวิธีกันพลาด
1กำหนดทิศ j₁ ตามใจ ไม่ยึดทิศลิงก์ได้ i₁ = −j₁ เครื่องหมายกลับหมดท่องกฎ: ทิศกระแสวงรอบ = ทิศลิงก์เสมอ
2ใช้ v₁ = (R₂+R₃) i₁ลืมหักกระแสของแหล่งจ่าย ผิดทั้งข้อกิ่งนอร์ตันต้องใช้ (i₁ − iₛ)
3คิดว่า R₂ ขนาน R₃ได้ R₂R₃/(R₂+R₃) แทน R₂+R₃ดูปม d — ดีกรี 2 ไม่มีทางแยก ⇒ อนุกรม
4วางขั้ว + ของ vk ไว้ที่หัวลูกศรเครื่องหมายของ v₁, v₂ กลับด้านประกาศข้อตกลงให้ชัดแล้วใช้ตลอด
5ลืมว่า vₛ ยกศักย์ขึ้นในทิศ o → aได้ v₂ = R₁i₂ + vₛไล่เดินจากขั้ว − ไป + แล้วบวก vₛ
6ไม่ยุบปมดีกรี 2ได้ b=5, n=4, l=2 ต้องแก้ 2 สมการคำตอบยังถูก แต่ยาวกว่าโดยไม่จำเป็น
7ตกใจที่ v₁, v₂ ติดลบคิดว่าคำนวณผิดค่าลบเป็นเรื่องปกติ แปลว่าศักย์ที่ปม a สูงกว่าปม o
