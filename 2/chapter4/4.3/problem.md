## 1. คำโจทย์ (ถอดความจากภาพ)

> **[4.3]** พิจารณาวงจรข่ายความต้านทานไฟฟ้าในรูปที่ 4บ.3(ก) และกำหนดให้แหล่งกำเนิดแรงดัน
> อิสระต่ออนุกรมกับตัวต้านทาน $R_1$ ตั้งอยู่บน **กิ่งที่ 2** และแหล่งกำเนิดกระแสอิสระต่อ
> ขนานกับผลอนุกรมของตัวต้านทาน $R_2$ และ $R_3$ ตั้งอยู่บน **กิ่งที่ 1** ดังที่แสดงทรีของวงจร
> ข่ายไว้ในรูปที่ 4บ.3(ข) ถ้ากำหนด $j_1$ เป็นกระแสวงรอบ แล้วจงเขียนสมการรอบและจง
> คำนวณหาค่าของแรงดันกิ่งและกระแสกิ่ง

## 3. สิ่งที่กำหนดให้ (Given)

| สัญลักษณ์ | ความหมาย | หน่วย |
|---|---|---|
| $v_s$ | แรงดันของแหล่งกำเนิดแรงดันอิสระ (ขั้ว + อยู่ด้านบน) | V |
| $i_s$ | กระแสของแหล่งกำเนิดกระแสอิสระ (ลูกศรชี้ขึ้น) | A |
| $R_1$ | ตัวต้านทานที่ต่ออนุกรมกับ $v_s$ | Ω |
| $R_2,\ R_3$ | ตัวต้านทานที่ต่ออนุกรมกัน แล้วนำไปขนานกับ $i_s$ | Ω |

**ข้อกำหนดเชิงโทโปโลยีที่โจทย์บังคับไว้**

- กิ่งที่ 2 $=$ $v_s$ อนุกรม $R_1$ (แบบจำลองรูปทีวินิน)
- กิ่งที่ 1 $=$ $i_s$ ขนาน $(R_2 + R_3)$ (แบบจำลองรูปนอร์ตัน)
- ทรีของกราฟ $=$ {กิ่งที่ 2} ดังนั้นลิงก์คือกิ่งที่ 1
- $j_1$ คือกระแสวงรอบของวงรอบพื้นฐานที่เกิดจากลิงก์ที่ 1

---

## 4. สิ่งที่ต้องหา (Find)

1. **สมการรอบ (loop equation)** ในรูปของ $j_1$
2. **กระแสกิ่ง** $i_1,\ i_2$
3. **แรงดันกิ่ง** $v_1,\ v_2$

## 5. ข้อตกลงเรื่องสัญกรณ์ที่ใช้ตลอดเฉลย

| สัญลักษณ์ | ความหมาย |
|---|---|
| $n$ | จำนวนปม (node) ของกราฟ |
| $b$ | จำนวนกิ่ง (branch) ของกราฟ |
| $l = b-n+1$ | จำนวนลิงก์ = จำนวนวงรอบอิสระ = จำนวนสมการรอบ |
| $i_k,\ v_k$ | กระแสกิ่งและแรงดันกิ่งของกิ่งที่ $k$ |
| $\mathbf{i}_b,\ \mathbf{v}_b$ | เวกเตอร์กระแสกิ่งและแรงดันกิ่ง |
| $\mathbf{B}$ | เมทริกซ์วงรอบพื้นฐาน (fundamental loop / tie-set matrix) |
| $\mathbf{j}$ | เวกเตอร์กระแสวงรอบ |
| $R_T$ | ตัวย่อของ $R_1+R_2+R_3$ |

**เครื่องหมายกำกับแบบสัมพันธ์ (associated reference direction)** — ลูกศรบนกิ่งบอกทิศของ $i_k$
และวางขั้ว $+$ ของ $v_k$ ไว้ที่ **หางลูกศร** เสมอ ทำให้ตัวต้านทานล้วนเป็นไปตาม $v=Ri$ โดยตรง
