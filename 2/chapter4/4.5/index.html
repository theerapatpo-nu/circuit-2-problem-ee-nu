โจทย์ [4.5] — Fundamental Tie-set Analysis

การวิเคราะห์วงจรข่ายความต้านทานที่มีแหล่งกำเนิดไม่อิสระประเภทแหล่งจ่ายกระแสควบคุมด้วยกระแส (CCCS)

📜 คำโจทย์ภาษาไทย (Problem Statement)

พิจารณาวงจรข่ายความต้านทานไฟฟ้าในรูปที่ 4บ.5(ก) กำหนดให้แหล่งกำเนิดกระแสอิสระต่อขนานกับตัวต้านทาน \(R_1\) ตั้งอยู่บน กิ่งที่ 3 และกำหนดให้แหล่งกำเนิดกระแสไม่อิสระต่อขนานกับตัวต้านทาน \(R_2\) ตั้งอยู่บน กิ่งที่ 2 และตัวต้านทาน \(R_3\) ตั้งอยู่บน กิ่งที่ 1 ดังที่แสดงทรีของวงจรข่ายไว้ในรูปที่ 4บ.5(ข) ถ้ากำหนดให้ \(j_1\) เป็นกระแสวงรอบหลักมูลแล้ว จงเขียนสมการรอบหลักมูลและจงคำนวณหาค่าของแรงดันกิ่งและกระแสกิ่ง
รูปที่ 4บ.5(ก) วงจรข่ายความต้านทาน (Resistive Network)
รูปที่ 4บ.5(ข) ทรีของกราฟของวงจรข่าย (Tree of Graph)

📐 การวิเคราะห์ทางโทโปโลยีและเมทริกซ์หลักมูล

วงจรมีจำนวนปม \(n = 3\), จำนวนกิ่ง \(b = 3\) ทำให้มีจำนวนวงรอบหลักมูล \(l = b - n + 1 = 1\) วงรอบ

1. เมทริกซ์วงรอบหลักมูล (Fundamental Tie-set Matrix): $$\mathbf{B} = \begin{bmatrix} 1 & 1 & -1 \end{bmatrix}$$ $$\mathbf{i}_b = \mathbf{B}^{\mathsf T} \mathbf{j} \implies i_1 = +j_1,\quad i_2 = +j_1,\quad i_3 = -j_1$$
2. ตัวแปรควบคุม (Controlling Variable): $$i_x = I_0 - i_3 = I_0 + j_1$$
3. สมการรอบหลักมูล (Fundamental Loop Equation): $$\mathbf{B} \mathbf{v}_b = 0 \implies v_1 + v_2 - v_3 = 0$$ $$[R_1 + (1 - \alpha)R_2 + R_3]\,j_1 = (\alpha R_2 - R_1)\,I_0$$
4. กระแสวงรอบหลักมูล (\(j_1\)): $$j_1 = \frac{(\alpha R_2 - R_1)\,I_0}{R_1 + (1 - \alpha)R_2 + R_3}$$
