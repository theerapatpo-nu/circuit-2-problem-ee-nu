CIRCUIT 2 · SIGNALS & SYSTEMS · ข้อ [7.6]

หา Impulse Response
จากสมการเชิงอนุพันธ์

บทเรียนแบบไล่ทีละบรรทัด ตั้งแต่นิยาม, Laplace transform, การแยกตัวประกอบ, pole-zero cancellation, ROC, ไปจนถึงการพิสูจน์และวิเคราะห์เสถียรภาพ

h(t) = etu(t)
โจทย์แผนแก้LaplaceแยกตัวประกอบPole–ZeroInverseตรวจคำตอบเสถียรภาพแบบทดสอบ

1) อ่านโจทย์ให้ถูก

กำหนด x(t) เป็น input, y(t) เป็น output และ initial conditions ทุกตัวเป็นศูนย์

y'''(t) + y'(t) − 2y(t) = x''(t) + x'(t) + 2x(t)

ฝั่ง output

อันดับสูงสุดคือ 3 จึงเป็น ODE อันดับ 3

y''' + 0y'' + y' − 2y

ฝั่ง input

อันดับสูงสุดคือ 2

x'' + x' + 2x

จุดที่พลาดบ่อยที่สุด: ฝั่งซ้ายคือ −2y(t) แต่ฝั่งขวาคือ +2x(t) เครื่องหมายต่างกัน

2) แผนที่การแก้โจทย์

3) ทำไมใช้ Laplace transform

Laplace transform เปลี่ยนโจทย์อนุพันธ์ให้เป็นพีชคณิต โดยเมื่อ initial conditions เป็นศูนย์

L{dnf/dtn} = snF(s)

แปลงฝั่ง y

L{y'''} + L{y'} − 2L{y} = s³Y(s) + sY(s) − 2Y(s)

แปลงฝั่ง x

L{x''} + L{x'} + 2L{x} = s²X(s) + sX(s) + 2X(s)

จัดกลุ่ม

(s³ + s − 2)Y(s) = (s² + s + 2)X(s)

สร้าง transfer function

H(s) = Y(s)/X(s) = (s²+s+2)/(s³+s−2)

4) แยกตัวประกอบแบบไม่ข้ามขั้น

เราต้องแยก s³+s−2 ให้ได้ก่อน โดยอย่าลืมว่ารูปเต็มคือ s³+0s²+s−2

Rational Root Theorem

รากตรรกยะที่เป็นไปได้คือ ±1 และ ±2

ทดลอง s = 1

1³ + 1 − 2 = 0

จึงรู้ว่า (s−1) เป็นตัวประกอบ

หารสังเคราะห์

ใช้สัมประสิทธิ์ 1, 0, 1, −2 จะได้ผลหาร s²+s+2 และเศษ 0

ผลการแยก

s³+s−2 = (s−1)(s²+s+2)

5) Pole–Zero Cancellation

H(s) = (s²+s+2) / [(s−1)(s²+s+2)] = 1/(s−1)

ก่อนตัด

Poles: 1 และ −½ ± j√7/2

Zeros: −½ ± j√7/2

หลังตัด

เหลือ pole ที่ s=1 จุดเดียว

ระบบที่มองจากภายนอกจึงมีพฤติกรรมอันดับ 1

เชิงวิศวกรรม: การตัดทอนนี้อธิบาย zero-state input-output behavior หาก initial conditions ไม่เป็นศูนย์ internal modes ที่ถูกตัดอาจยังปรากฏได้

6) Inverse Laplace และ ROC

1/(s−a) ↔ eatu(t),   ROC: Re{s} > a

ในข้อนี้ a=1 และเลือก causal system จึงใช้ ROC ทางขวาของ pole

H(s) = 1/(s−1)   ⟹   h(t) = etu(t),   Re{s}>1
แล้วถ้าเลือก ROC ทางซ้ายล่ะ?

ถ้า Re{s}<1 จะได้ −eᵗu(−t) ซึ่งเป็น anti-causal response ไม่ใช่คำตอบ causal ที่ใช้ในโจทย์นี้

7) ตรวจสอบคำตอบให้ครบ

ตรวจสำหรับ t > 0

เมื่อพ้นจุด impulse แล้ว x(t)=0 และ h=eᵗ ทำให้

h''' + h' − 2h = eᵗ + eᵗ − 2eᵗ = 0

ตรวจ jump ที่ t=0

หลัง cancellation ระบบสมมูลคือ h'−h=δ(t) อินทิเกรตจาก 0⁻ ถึง 0⁺:

h(0⁺) − h(0⁻) = 1

เพราะ causal response มี h(0⁻)=0 จึงได้ h(0⁺)=1 ตรงกับ e⁰=1

ผลตรวจเชิงตัวเลข: การจำลองระบบอันดับ 3 ทับกับ eᵗ โดยมี maximum relative error ประมาณ 7.49×10⁻⁴

8) Causality และ Stability

เป็น causal

เพราะ h(t)=0 สำหรับ t<0 เนื่องจากมี u(t)

ไม่ BIBO stable

เพราะ ∫₀∞eᵗdt = ∞ และ pole s=+1 อยู่ใน right-half plane

9) แผนสอน 60 นาที

0–5 นาทีอ่านโจทย์
5–15 นาทีทบทวน Laplace
15–25 นาทีแปลง ODE
25–38 นาทีแยกตัวประกอบ
38–52 นาทีPoles, ROC, inverse
52–60 นาทีพิสูจน์และสรุป

10) แบบทดสอบท้ายบท

เลือกคำตอบแล้วกด “ตรวจคำตอบ” คะแนนจะถูกคำนวณในเครื่องนี้เท่านั้น

สรุปบรรทัดเดียว

(s³+s−2)Y=(s²+s+2)X ⟹ H(s)=1/(s−1) ⟹ h(t)=etu(t)

คุณสมบัติ: causal, ROC Re{s}>1, pole ที่ +1, ไม่ BIBO stable
