# คำศัพท์ — Network Topology สำหรับวงจรไฟฟ้า

## คำศัพท์ทั่วไป

### Branch (กิ่ง)

เส้นทางหนึ่งในกราฟ แทนอุปกรณ์หรือสายต่อระหว่างสองปมในวงจร มีตัวแปรกระแส $i_j$ กำกับ

### Connected Graph (กราฟเชื่อมต่อ)

กราฟที่ทุกคู่ปมสามารถเดินทางถึงกันได้โดยกิ่งในกราฟ

### Cycle / Loop (วงรอบ)

เส้นทางปิดที่เริ่มและจบที่ปมเดียวกัน ไม่ผ่านกิ่งซ้ำ

### Directed Graph (กราฟมีทิศทางกำกับ)

กราฟที่แต่ละกิ่งมีทิศทางจากปมหนึ่งไปอีกปมหนึ่ง

### Edge (กิ่ง)

เหมือนกับ branch ในบริบทนี้

### Graph (กราฟ)

โครงสร้าง $G = (V, E)$ ประกอบด้วยปม $V$ และกิ่ง $E$

### Incidence Matrix (เมทริกซ์ incidence)

เมทริกซ์ $n \times b$ ที่แสดงความสัมพันธ์ระหว่างปมกับกิ่ง โดยมีค่า $+1$ ถ้ากิ่งออกจากปม $-1$ ถ้ากิ่งเข้าปม และ $0$ ถ้าไม่เกี่ยวข้อง

### KCL (Kirchhoff's Current Law)

กฎของเคอร์ชอฟว่าด้วยกระแส: ผลรวมกระแสที่เข้าปม (หรือออกจากปม) เท่ากับศูนย์

### KVL (Kirchhoff's Voltage Law)

กฎของเคอร์ชอฟว่าด้วยแรงดัน: ผลรวมแรงดันตามวงรอบปิด เท่ากับศูนย์

### Laplacian Matrix (เมทริกซ์ Laplacian)

เมทริกซ์ $L = A_a A_a^T$ ที่ใช้หาจำนวน spanning tree ผ่าน Matrix-Tree Theorem

### Link (กิ่งนอก tree)

กิ่งของกราฟที่ไม่อยู่ใน spanning tree ที่เลือก

### Node / Vertex (ปม)

จุดในกราฟ แทนจุดต่อหรือบัสในวงจร

### Spanning Tree (ต้นไม้ทอดข้าม)

ต้นไม้ย่อยของกราฟที่มีปมครบทุกปมและไม่มีวงรอบ

### Tree (ต้นไม้)

กราฟเชื่อมต่อที่ไม่มีวงรอบ

### Twig (กิ่งใน tree)

กิ่งที่อยู่ใน spanning tree ที่เลือก

## คำศัพท์เฉพาะ Cutset

### Branch-Current Vector

เวกเตอร์คอลัมน์ของกระแสในแต่ละกิ่ง $i_b = [i_1, i_2, \dots, i_b]^T$

### Cutset (ชุดตัด)

เซตย่อยของกิ่งที่เมื่อนำออกจะทำให้กราฟแยกเป็นสองส่วนที่ไม่เชื่อมต่อกัน

### Cutset Equation (สมการเซตตัด)

สมการ KCL ที่เขียนสำหรับ supernode ที่เกิดจากการตัดกิ่งใน cutset ออก

### Cutset Matrix $Q_f$ (เมทริกซ์เซตตัด)

เมทริกซ์ที่รวมสมการ fundamental cutset ทั้งหมด

### Fundamental Cutset (ชุดตัดพื้นฐาน)

ชุดตัดที่เกิดจากการตัด twig หนึ่งกิ่งออกจาก spanning tree

### Independent Cutset (ชุดตัดอิสระ)

ชุดตัดที่สมการของแต่ละชุดเป็นอิสระต่อกันเชิงเส้น จำนวนเท่ากับ $n-1$

### Matrix-Tree Theorem

ทฤษฎีบทที่กล่าวว่าจำนวน spanning tree ของกราฟเท่ากับ cofactor ของ Laplacian matrix

### Reduced Incidence Matrix

Incidence matrix ที่ลบแถวของปมอ้างอิง (ground) ออก มีขนาด $(n-1) \times b$

### Supernode (ซุปเปอร์โนด)

กลุ่มปมที่ถือเป็นปมเดียวกันเมื่อตัดกิ่งใน cutset ออก

## ตัวอักษรและสัญลักษณ์

| สัญลักษณ์ | ความหมาย |
|:---|:---|
| $n$ | จำนวนปม (nodes) |
| $b$ | จำนวนกิ่ง (branches) |
| $G$ | กราฟ |
| $V$ | เซตของปม |
| $E$ | เซตของกิ่ง |
| $L$ | Laplacian matrix |
| $A_a$ | Incidence matrix แบบเต็ม |
| $A$ | Reduced incidence matrix |
| $Q_f$ | Fundamental cutset matrix |
| $i_b$ | Branch-current vector |
| $T$ | Spanning tree |
| $\tau(G)$ | จำนวน spanning tree ของกราฟ $G$ |
