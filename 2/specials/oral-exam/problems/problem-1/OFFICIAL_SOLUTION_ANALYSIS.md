## 1. สรุปขั้นตอนคำนวณและตัวเลขคำตอบจากเฉลยอาจารย์ (Step-by-Step Breakdown)

จากเอกสารลายมืออาจารย์ [งาน คสช. (1).pdf](reference/%E0%B8%87%E0%B8%B2%E0%B8%99%20%E0%B8%84%E0%B8%AA%E0%B8%8A.%20(1).pdf) อาจารย์ไม่ได้ใช้อัลกอริทึม Curve Fitting คอมพิวเตอร์โดยตรง แต่ใช้ **การวิเคราะห์เชิงวิศวกรรมและการประมาณช่วง (Piecewise Asymptotic Analysis)** ในการแก้หาค่าพารามิเตอร์ทั้งหมดด้วยมือตามลำดับขั้นตอนดังนี้:

### 1.1 ขั้นตอนที่ 1: คำนวณกระแส $i(t)$ ด้วยสมการโหนด (Nodal Analysis / KCL)
* **สมการ KCL ที่ Node 1:**
  $$i(t) = i_s(t) + \frac{v(t)}{R_L} \quad (\text{เมื่อ } R_L = 10\ \Omega)$$
* **สุ่มคำนวณ 3 จุดเวลา:**
  * ณ $t = 0\text{ s}$: $i(0) = 0.32258956 + \frac{4.1741044}{10} = \mathbf{0.74\text{ A}}$
  * ณ $t = 10\text{ s}$: $i(10) = 0.32379514 + \frac{4.1620486}{10} = \mathbf{0.74\text{ A}}$
  * ณ $t = 100\text{ s}$: $i(100) = 0.33191478 + \frac{4.0808522}{10} = \mathbf{0.74\text{ A}}$
* **ข้อสรุปสำคัญของอาจารย์:** กระแส $i(t) = \mathbf{0.74\text{ A}}$ มีค่าคงที่เท่ากันตลอดทุกช่วงเวลา!

---

### 1.2 ขั้นตอนที่ 2: คำนวณประจุสะสม $q(t)$ และความจุรวม $Q_n$ (Integration)
* **สูตรความสัมพันธ์ $i = \frac{dq}{dt} \implies q(t) = \int_0^t i(\alpha) d\alpha$:**
  $$q(t) = \int_{0}^{t} 0.74 \, d\alpha = \mathbf{0.74 t\text{ [Coulombs]}}$$
* **ความจุประจุรวมตามทฤษฎี $Q_n$ ($t_n = 3,600\text{ s}$):**
  $$Q_n = \int_{0}^{3600} 0.74 \, d\alpha = 0.74 \times 3,600 = \mathbf{2,664\text{ [Coulombs]}}$$

---

### 1.3 ขั้นตอนที่ 3: การตั้งสมการ KVL และลดรูปสมการ (KVL & Model Reduction)
* จาก KVL ลูปซ้าย: $v(t) = v_s(t) - i(t)R_i = v_s(t) - 0.74 R_i$
* แทนค่า $v_s(t)$:
  $$v(t) = \underbrace{(E_o - 0.74 R_i)}_{E_o'} - K \cdot q(t) + A_a e^{-B_a q(t)} - A_b e^{-B_b (2664 - q(t))}$$

---

### 1.4 ขั้นตอนที่ 4: การหาค่า $K$ และ $E_o'$ จากช่วงเชิงเส้น (Linear Zone Fitting: $y = mx + c$)
* **สมมติฐาน:** ในช่วงกลางของการคายประจุ ($q \in [1000, 1400]$ C)
  * เทอมเอ็กซ์โพเนนเชียลทั้งสองช่วงมีค่าเข้าใกล้ 0 ($e^{-B_a q} \approx 0$ และ $e^{-B_b (2664-q)} \approx 0$)
  * สมการลดรูปเป็นสมการเส้นตรง: $v(t) \approx -K \cdot q(t) + E_o'$
* **ความชัน $-K$ (Linear Slope):**
  $$-K = \frac{v(1000) - v(1400)}{q(1000) - q(1400)} = \frac{3.8353 - 3.7264}{1000 - 1400} = -2.724 \times 10^{-4}\text{ V/C}$$
  $$\mathbf{K = 2.724 \times 10^{-4}\text{ [V/C]}}$$
* **จุดตัดแกน $E_o'$ ($E_o - 0.74 R_i$):**
  $$3.8353 = -2.724 \times 10^{-4}(1000) + E_o' \implies \mathbf{E_o' = E_o - 0.74 R_i = 4.03687\text{ [V]}}$$

---

### 1.5 ขั้นตอนที่ 5: การหาค่า $R_i$
* ใช้ค่าแรงดัน $E_o \approx v(100) = 4.0801\text{ V}$
  $$R_i = \frac{E_o - E_o'}{0.74} = \frac{4.0801 - 4.036876}{0.74} = \mathbf{0.0584\ [\Omega]}$$

---

### 1.6 ขั้นตอนที่ 6: การหาพารามิเตอร์ช่วงแรก $A_a$ และ $B_a$ (Initial Exponential Zone)
* ณ $t = 0$ ($q=0$): $e^{-B_a(0)} = 1$
  $$v(0) = E_o' + A_a \implies 4.1741 = 4.03687 + A_a \implies \mathbf{A_a = 0.13723\text{ [V]}}$$
* ณ $t = 100\text{ s}$ ($q=74\text{ C}$): $v(100) = 4.081\text{ V}$
  $$4.081 = 4.03687 - (2.724 \times 10^{-4} \times 74) + 0.13723 e^{-74 B_a}$$
  $$\mathbf{B_a = 0.01533\text{ [1/C]}}$$

---

### 1.7 ขั้นตอนที่ 7: การหาพารามิเตอร์ช่วงท้าย $A_b$ และ $B_b$ (End Exponential Zone)
* ณ ช่วง $t \ge 2700\text{ s}$ ($q \ge 1998\text{ C}$): $e^{-B_a q} \approx 0$
  * ณ $t = 2700\text{ s}$ ($q=1998\text{ C}$): $A_b e^{-666 B_b} = 0.44257 \quad \text{--- (สมการ 1)}$
  * ณ $t = 2750\text{ s}$ ($q=2035\text{ C}$): $A_b e^{-629 B_b} = 0.65820 \quad \text{--- (สมการ 2)}$
* อัตราส่วนสมการ (1)/(2): $e^{-37 B_b} = \frac{0.44257}{0.65820} = 0.6724$
  $$\mathbf{B_b = 0.0107\text{ [1/C]}}$$
  $$\mathbf{A_b = 551.176\text{ [V]}}$$

## 3. วิเคราะห์ศาสตร์ทางวิศวกรรมไฟฟ้าที่ใช้ในเฉลยนี้ (Disciplines & Knowledge Applied)

เฉลยของอาจารย์ในไฟล์ [งาน คสช. (1).pdf](reference/%E0%B8%87%E0%B8%B2%E0%B8%99%20%E0%B8%84%E0%B8%AA%E0%B8%8A.%20(1).pdf) ใช้ศาสตร์ 4 สาขาหลักในการแก้ปัญหา:

```
+-----------------------------------------------------------------------------------+
|                        ศาสตร์ที่ใช้ในเฉลยของอาจารย์ (Official Solution)              |
+----------------------------------------+------------------------------------------+
|  1. Circuit Theory (KCL & KVL)         |  2. Electrostatics & Charge Dynamics      |
|  - สมการโหนด KCL ที่ Node 1            |  - ความสัมพันธ์กระแสและประจุ i = dq/dt    |
|  - สมการลูป KVL ฝั่งซ้าย                 |  - อินทิกรัลประจุสะสม q(t) และ Q_n       |
+----------------------------------------+------------------------------------------+
|  3. Battery Electrochemical Modeling   |  4. Asymptotic Piecewise Analysis        |
|  - แบบจำลอง Shepherd / Tremblay        |  - การแยกช่วงฟังก์ชัน (Linear / Exp Zone)|
|  - พฤติกรรม OCV, R_i, Exp Drop Zones   |  - การแก้ระบบสมการด้วย Linear Regression |
+----------------------------------------+------------------------------------------+
```

1. **ศาสตร์ที่ 1: ทฤษฎีวงจรไฟฟ้า (Electric Circuit Theory - KCL & KVL):**
   * ใช้ KCL พิสูจน์ว่า $i(t) = i_s(t) + \frac{v(t)}{10} = 0.74\text{ A}$ ( Constant Current Discharge)
   * ใช้ KVL ตั้งสมการแรงดันขั้ว $v(t) = v_s(t) - 0.74 R_i$

2. **ศาสตร์ที่ 2: ฟิสิกส์ประจุไฟฟ้า (Charge Dynamics & Integration):**
   * ใช้ความสัมพันธ์ $i(t) = \frac{dq}{dt} \implies q(t) = \int_0^t i(\alpha)d\alpha = 0.74t$ และ $Q_n = 2,664\text{ C}$

3. **ศาสตร์ที่ 3: แบบจำลองแบตเตอรี่เคมีไฟฟ้า (Electrochemical Battery Modeling):**
   * อธิบายโครงสร้างแบบจำลองแบตเตอรี่ 2 เอ็กซ์โพเนนเชียล (Shepherd / Tremblay Model)

4. **ศาสตร์ที่ 4: การวิเคราะห์อัศวินท็อตแบบแยกช่วง (Piecewise Asymptotic Analysis & System Identification):**
   * นี่คือ **"จุดพีคเชิงวิชาการ"** ในเฉลยของอาจารย์! แทนที่จะต้องรันโปรแกรมคอมพิวเตอร์ซับซ้อน อาจารย์ใช้หลักการประมาณค่าช่วงเพื่อตัดเทอมที่ไม่ส่งผลออก ($e^{-B_a q} \approx 0$ และ $e^{-B_b (Q_n-q)} \approx 0$) ทำให้สมการนอนลินียร์ลดรูปเป็นสมการเส้นตรง $y = mx + c$ เพื่อหา $K$ และ $E_o'$ แล้วใช้พีชคณิตธรรมดาแก้หา $A_a, B_a, A_b, B_b$ ได้โดยง่าย!
