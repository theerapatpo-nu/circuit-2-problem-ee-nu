## 1. ถอดข้อความจากโจทย์ต้นฉบับ (Transcribed Problem Text)

**โจทย์:**
[1] พิจารณาวงข่ายความต้านทานใน[รูปที่ 1](file:///Users/3rapat/student/internship/CODEFIN/project/vahalla-wealth/private-docs/other-project/uni-work/engineering-problem/circuit/2/specials/oral-exam/circuit_fig1.png) ด้วยการใช้สมการชุดตัดหรือสมการโหนด จงหาค่าของกระแส $i(t)$ ในหน่วยแอมป์ ณ เวลา $t \in \{0, 1, 2, \dots, 2752\}$ วินาที พร้อมหาค่าพารามิเตอร์ $E_o, K, A_a, B_a, A_b, B_b, R_i$ และ $Q_n$ ของ $v_s(t)$ ซึ่งเป็นฟังก์ชันของเวลาของแหล่งกำเนิดแรงดันในหน่วยโวลต์ และมีนิยามว่า

$$v_s(t) = E_o - K \int_{0}^{t} i(\alpha) d\alpha + A_a e^{-B_a \int_{0}^{t} i(\alpha) d\alpha} - A_b e^{-B_b \int_{t}^{t_n} i(\alpha) d\alpha}$$

และกำหนด $Q_n$ คือค่าความจุประจุหรือปริมาณการเก็บพลังงานไฟฟ้าตามทฤษฎีที่ผู้ผลิตกำหนดไว้ช่วงเวลาตั้งแต่ 0 [วินาที] ถึง $t_n$ [วินาที] สำหรับแบตเตอรี่ดังกล่าวคือ $Q_n = \int_{0}^{t_n} i(\alpha) d\alpha \text{ [coulomb]}$ และ $t_n = 3,600 \text{ [วินาที]}$ กำหนด $R_L$ คือค่าความต้านทานของภาระไฟฟ้า ซึ่งมีค่า $R_L = 10 \ [\Omega]$ และกำหนด $i_s(t)$ คือฟังก์ชันของเวลาของแหล่งกำเนิดกระแสพึ่งพาในหน่วยแอมป์ ซึ่งมีค่าบรรจุอยู่ในไฟล์ [data303212qz02.md](file:///Users/3rapat/student/internship/CODEFIN/project/vahalla-wealth/private-docs/other-project/uni-work/engineering-problem/circuit/2/specials/oral-exam/data303212qz02.md) (แปลงจาก [data303212qz02.xls](file:///Users/3rapat/student/internship/CODEFIN/project/vahalla-wealth/private-docs/other-project/uni-work/engineering-problem/circuit/2/specials/oral-exam/data303212qz02.xls)) และกำหนด $v(t)$ คือฟังก์ชันแรงดันที่ตกคร่อมตัวต้านทานภาระไฟฟ้าของเวลา $t$ ในหน่วยโวลต์ ซึ่งมีค่าบรรจุอยู่ในไฟล์ [data303212qz02.md](file:///Users/3rapat/student/internship/CODEFIN/project/vahalla-wealth/private-docs/other-project/uni-work/engineering-problem/circuit/2/specials/oral-exam/data303212qz02.md) และกำหนด $E_o$ คือแรงดันคงที่ในหน่วยโวลต์ และกำหนด $K$ คือค่าคงที่โพลาไรเซชันในหน่วยโวลต์ต่อคูลอมบ์ และ $A_a$ คือค่าขนาดของแรงดันเลขชี้กำลังในหน่วย [โวลต์] และ $B_a$ คือค่าคงที่ความจุประจุเลขชี้กำลังในหน่วย [1/คูลอมบ์] ช่วงเวลาตั้งแต่ 0 [วินาที] ถึง $t$ [วินาที] และกำหนด $A_b$ คือขนาดแรงดันเลขชี้กำลังในหน่วย [โวลต์] และ $B_b$ คือค่าคงที่ความจุประจุเลขชี้กำลังในหน่วย [1/คูลอมบ์] ช่วงเวลาตั้งแต่ $t$ [วินาที] ถึง $t_n$ [วินาที]

### 3.2 การวิเคราะห์รายละเอียดขององค์ประกอบในรูปภาพ (Detailed Breakdown of Diagram Visuals)

#### 1. แหล่งกำเนิดแรงดัน $v_s(t)$ (ซ้ายสุด)
* **ลักษณะทางทัศนวิสัย:** สัญลักษณ์วงกลม ข้างในมีเครื่องหมายบวก ($+$) อยู่ด้านบน และเครื่องหมายลบ ($-$) อยู่ด้านล่าง ด้านซ้ายมีกำกับด้วยข้อความ $v_s(t)$
* **การต่อในวงจร:** วางอยู่ในกิ่งซ้ายสุด ขั้วลบ ($-$) ต่อกับสายเส้นล่างสุด (Reference Node / Ground) ส่วนขั้วบวก ($+$) ต่ออนุกรมเข้ากับตัวต้านทาน $R_i$
* **การเชื่อมโยงกับโจทย์:** 
  * ใช้ในสมการ KVL สำหรับลูปซ้าย: $v_s(t) - i(t)R_i = v(t)$
  * มีความสัมพันธ์กับสมการแบบจำลองแบตเตอรี่ในโจทย์:
    $$v_s(t) = E_o - K \int_{0}^{t} i(\alpha) d\alpha + A_a e^{-B_a \int_{0}^{t} i(\alpha) d\alpha} - A_b e^{-B_b \int_{t}^{t_n} i(\alpha) d\alpha}$$
  * เกี่ยวข้องโดยตรงกับพารามิเตอร์ที่โจทย์สั่งให้หาทั้งหมด 8 ตัว ได้แก่ $E_o, K, A_a, B_a, A_b, B_b, R_i, Q_n$

#### 2. ตัวต้านทานความต้านทานภายใน $R_i$ (กิ่งบนซ้าย)
* **ลักษณะทางทัศนวิสัย:** รูปสี่เหลี่ยมผืนผ้ากรอบหนา วางขนานบนสายเส้นบน มีข้อความ $R_i$ กำกับอยู่ด้านบนสี่เหลี่ยม
* **การต่อในวงจร:** ต่ออนุกรมอยู่ระหว่างขั้วบวก ($+$) ของ $v_s(t)$ กับโหนดบน (Node 1) ที่มีกระแส $i(t)$ ไหลผ่าน
* **การเชื่อมโยงกับโจทย์:**
  * เกี่ยวข้องกับโจทย์ในประโยคที่ระบุว่า "...พร้อมหาค่าพารามิเตอร์ $E_o, K, A_a, B_a, A_b, B_b, R_i$..."
  * เป็นตัวแปรที่ทำให้เกิดแรงดันตกภายในแบตเตอรี่ $i(t)R_i$ ส่งผลให้แรงดันที่ขั้วแบตเตอรี่ที่วัดได้จริงคือ $v(t) = v_s(t) - i(t)R_i$

#### 3. กระแส $i(t)$ (สายบนตรงกลาง)
* **ลักษณะทางทัศนวิสัย:** สัญลักษณ์ลูกศรป้านสีดำชี้ไปทางขวาบนสายเส้นบน มีข้อความ $i(t)$ กำกับอยู่ด้านบนลูกศร
* **การต่อในวงจร:** เป็นกระแสที่ไหลออกจากขั้วแบตเตอรี่ (ผ่าน $R_i$) มุ่งหน้าเข้าสู่โหนดขนาน (Node 1) ทางขวา
* **การเชื่อมโยงกับโจทย์:**
  * เป็นเป้าหมายหลักประการแรกที่โจทย์สั่งให้คำนวณ: "...จงหาค่าของกระแส $i(t)$ ในหน่วยแอมป์ ณ เวลา $t \in \{0, 1, 2, \dots, 2752\}$ วินาที..."
  * ใช้ในสมการชุดตัด / สมการโหนด (KCL at Node 1): $i(t) = i_s(t) + \frac{v(t)}{R_L}$
  * ปรากฏอยู่ในเทอมอินทิกรัล $i(\alpha)d\alpha$ เพื่อคำนวณประจุไฟฟ้าสะสม $q(t) = \int_0^t i(\alpha)d\alpha$ และความจุทั้งหมด $Q_n = \int_0^{t_n} i(\alpha)d\alpha$

#### 4. แหล่งกำเนิดกระแสพึ่งพา $i_s(t)$ (กิ่งกลาง)
* **ลักษณะทางทัศนวิสัย:** สัญลักษณ์รูปสี่เหลี่ยมข้าวหลามตัด (Diamond) ภายในมีลูกศรชี้ลงด้านล่าง มีข้อความ $i_s(t)$ กำกับอยู่ทางด้านซ้าย
* **การต่อในวงจร:** ต่อเป็นกิ่งแนวดิ่งตรงกลางระหว่างโหนดบน (Node 1) กับสายล่างสุด (Ground) โดยทิศทางกระแสไหลจากโหนดบนลงสู่ Ground
* **การเชื่อมโยงกับโจทย์:**
  * เกี่ยวข้องกับโจทย์ในประโยค: "...กำหนด $i_s(t)$ คือฟังก์ชันของเวลาของแหล่งกำเนิดกระแสพึ่งพา... บรรจุอยู่ในไฟล์ [data303212qz02.md](data303212qz02.md)..."
  * ใช้เป็นค่าเข้า (Known Input Data จากคอลัมน์ `is(t) [A]`) ในสมการ KCL เพื่อหาค่า $i(t)$

#### 5. ตัวต้านทานภาระไฟฟ้า $R_L$ (กิ่งขวาสุด)
* **ลักษณะทางทัศนวิสัย:** รูปสี่เหลี่ยมผืนผ้ากรอบหนาวางในแนวดิ่ง มีข้อความ $\text{R}_\text{L}$ กำกับอยู่ทางด้านซ้ายของตัวต้านทาน
* **การต่อในวงจร:** ต่อเป็นกิ่งแนวดิ่งขวาสุด ขนานกับแหล่งกำเนิดกระแสพึ่งพา $i_s(t)$ ระหว่างโหนดบน (Node 1) กับสายล่างสุด (Ground)
* **การเชื่อมโยงกับโจทย์:**
  * เกี่ยวข้องกับโจทย์ในประโยค: "...กำหนด $R_L$ คือค่าความต้านทานของภาระไฟฟ้า ซึ่งมีค่า $R_L = 10\ [\Omega]$..."
  * ใช้คำนวณกระแสที่ไหลผ่านภาระ $i_L(t) = \frac{v(t)}{R_L} = \frac{v(t)}{10}$ ในสมการโหนด/ชุดตัด

#### 6. แรงดันตกคร่อมภาระ $v(t)$ (ขวาสุดของวงจร)
* **ลักษณะทางทัศนวิสัย:** เครื่องหมายบวก ($+$) อยู่ด้านบน และเครื่องหมายลบ ($-$) อยู่ด้านล่าง ด้านขวามีข้อความ $v(t)$ กำกับระหว่างเครื่องหมาย
* **การต่อในวงจร:** เป็นขั้ววัดแรงดันตกคร่อมตัวต้านทานภาระ $R_L$ (และเป็นแรงดันตกคร่อมโหนดบนเทียบกับ Ground)
* **การเชื่อมโยงกับโจทย์:**
  * เกี่ยวข้องกับโจทย์ในประโยค: "...และกำหนด $v(t)$ คือฟังก์ชันแรงดันที่ตกคร่อมตัวต้านทานภาระไฟฟ้า... บรรจุอยู่ในไฟล์ [data303212qz02.md](data303212qz02.md)..."
  * เป็นแรงดันโหนด $v_1(t) = v(t)$ (ข้อมูลในคอลัมน์ `v(t) [volt]`) ที่ใช้ในสมการโหนด และใช้เป็นค่าอ้างอิงในการทำ Curve Fitting เพื่อประมาณค่าพารามิเตอร์แบตเตอรี่
