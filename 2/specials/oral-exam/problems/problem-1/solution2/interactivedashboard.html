vs(t) = Eo − K ∫₀ᵗ i(α) dα + Aa e−Ba ∫₀ᵗ i(α) dα − Ab e−Bb ∫ₜᵗⁿ i(α) dα

Feynman from zero

เริ่มจากท่อน้ำ ไม่เริ่มจากท่องสูตร

ให้จินตนาการว่าประจุเป็นน้ำ วงจรเป็นท่อ และแบตเตอรี่เป็นปั๊มที่ยกพลังงานให้ “น้ำไฟฟ้า” ทุกคูลอมบ์ ภาพนี้ทำให้กฎวงจรสองข้อกลายเป็นกฎอนุรักษ์ที่สามัญมาก

Voltage v — แรงดัน/ความสูงพลังงานต่อประจุ 1 V = 1 J/C ต้องวัดระหว่างสองจุดเสมอ
Current i — อัตราการไหลประจุที่ผ่านต่อเวลา 1 A = 1 C/s
Resistance R — ท่อที่ต้านการไหลท่อแคบต้องใช้แรงดันมากขึ้นเพื่อคงอัตราไหล: v = iR
Battery — ปั๊ม + ความฝืดภายในvₛ เป็นแรงดันภายใน และ iRi คือแรงดันที่สูญเสียภายในเมื่อมีกระแส

KCL: น้ำเข้าจุดแยก = น้ำออกทั้งหมด

i(t) = iₛ(t) + iL(t) = iₛ(t) + v(t)/RL

โหนดไม่สามารถสร้างหรือทำลายประจุเองได้ หากกระแสเข้า 0.74 A กระแสสองกิ่งขาออกต้องรวมกันได้ 0.74 A พอดี

KVL: เดินกลับจุดเดิม พลังงานสุทธิต่อประจุต้องเป็นศูนย์

+vₛ(t) − i(t)Ri − v(t) = 0 ⇒ v(t) = vₛ(t) − i(t)Ri

แบตเตอรี่ยกแรงดันขึ้น ตัวต้านทานภายในและโหลดทำให้แรงดันตก เมื่อล้อมครบวงจรต้องกลับมาศักย์เดิม

ข้อจำกัดของภาพท่อน้ำ: พลังงานในวงจรจริงถ่ายทอดผ่านสนามแม่เหล็กไฟฟ้า ไม่ใช่อิเล็กตรอนวิ่งจากโรงไฟฟ้ามาถึงโหลดด้วยความเร็วแสง ภาพท่อน้ำใช้เพื่อเข้าใจความต่างศักย์และการอนุรักษ์เท่านั้น
Step-by-step derivation

ทุกบรรทัดมีเหตุผลและหน่วยรองรับ

1) เขียน KCL ที่ Node 1

−i(t) + iₛ(t) + v(t)/10 = 0
∴ i(t) = iₛ(t) + v(t)/10

2) แทนค่าที่ t = 0 s

i(0) = 0.3225895591500284 + 4.174104408499716/10 = 0.740000 A

เมื่อตรวจครบ 2,753 แถว ได้ min = max = mean = 0.74 A ส่วนเบี่ยงเบนระดับ 10⁻¹⁶ A เป็นเพียง floating-point roundoff

3) อินทิเกรตเพื่อหาประจุ

q(t) = ∫₀ᵗ 0.74 dα = 0.74t C

หน่วยตรวจสอบได้ทันที: A·s = (C/s)·s = C และ q(2752) = 2036.48 C

4) ความจุตามนิยามของโจทย์

Qn = ∫₀³⁶⁰⁰ 0.74 dα = 0.74×3600 = 2664 C = 0.74 Ah

ข้อมูลหยุดที่ 2752 s การไปถึง 3600 s จึงใช้สมมติฐานกระแส 0.74 A ต่อเนื่องตามนิยามโจทย์

5) แรงดันขั้ว

v = Eo − Kq + Aa·exp(−Ba·q) − Ab·exp[−Bb(Qn−q)] − iRi
Nonlinear identification

ฟิตให้แม่น และรู้ว่าอะไร “ฟิตไม่ได้”

Objective function

SSE(θ) = Σₖ [vₖ − v̂(qₖ, iₖ; θ)]²

พารามิเตอร์ Ba, Bb อยู่ใน exponent จึงเป็น nonlinear least squares สคริปต์ใช้ global search ที่อัตราทั้งสอง ตามด้วย bounded trust-region polish

Variable projection

เมื่อกำหนด Ba, Bb แล้ว C₀, K, Aa, Ab เป็นปัญหา linear least squares จึงลดมิติ nonlinear จากหกเหลือสองก่อน ทำให้หลบ local minimum ได้ดีขึ้น

Structural identifiability

∂v̂/∂Eo = 1,    ∂v̂/∂Ri = −i = −0.74

คอลัมน์ Jacobian เป็นสัดส่วนกันทุกแถว จึงเห็นเพียง C₀ = Eo − 0.74Ri ค่าเดียว ทุกคู่บนเส้น Eo = 4.036467052577080 + 0.74Ri ให้เส้นแรงดันเดียวกัน

Ab ≈ 559.95 V เป็น coefficient ณ q = Qn ไม่ใช่แรงดันใช้งานจริง จุดข้อมูลสุดท้ายยังเหลือประจุ 627.52 C ทำให้ผลของเทอมนี้ ณ จุดนั้นประมาณ 0.669 V เท่านั้น อย่า extrapolate ถึง 3600 s โดยไม่มีข้อมูลเพิ่ม

วิธีคิดคำนวณด้วยมือแบบเฉลยอาจารย์ (งาน คสช.)

ในเฉลยลายมืออย่างเป็นทางการของอาจารย์ (ไฟล์ งาน คสช. (1).pdf) อาจารย์ไม่ได้ใช้คอมพิวเตอร์รัน Curve Fitting โดยตรง แต่ใช้เทคนิค Piecewise Asymptotic Approximation (การประมาณช่วงเชิงเส้น) ในการหาพารามิเตอร์ทั้งหมดด้วยมืออย่างเหนือชั้น:

1) KCL ที่ Node 1: พิสูจน์กระแส i(t) = 0.74 A (ค่าคงที่)

i(t) = iₛ(t) + v(t)/10

สุ่มแทนค่าที่ t = 0s, 10s, 100s ได้ 0.74 A เท่ากันทุกจุด แสดงว่ากระแสจ่ายคงที่ตลอดทุกช่วงเวลา

2) การอินทิเกรตหาประจุ q(t) และ Qₙ

q(t) = ∫₀ᵗ 0.74 dα = 0.74t C   |   Qₙ = ∫₀³⁶⁰⁰ 0.74 dα = 2,664 C

3) หา K และ E₀' จากช่วงเชิงเส้น (q ∈ [1000, 1400] C)

ช่วงกลางการคายประจุ เทอม exponential ทั้งสองเข้าใกล้ 0 ทำให้ v(t) ≈ −K·q(t) + E₀' (เส้นตรง y = mx + c)

−K = Δv / Δq = (3.8353 − 3.7264) / (1000 − 1400) = −2.724×10⁻⁴ V/C ⇒ K = 2.724×10⁻⁴ V/C
E₀' = E₀ − 0.74Rᵢ = 4.03687 V

4) หา Rᵢ (สมมติ E₀ = v(100) = 4.0801 V)

Rᵢ = (E₀ − E₀') / 0.74 = (4.0801 − 4.03687) / 0.74 = 0.0584 Ω

5) หา Aₐ, Bₐ (ช่วงเริ่มคาย) และ A_b, B_b (ช่วงปลายคาย)

Oral defense

คำถามที่กรรมการอาจยิง — และแก่นของคำตอบ

ทำไม i(t) เท่ากับ 0.74 A ทุกเวลา?

KCL ให้ i=iₛ+v/10 และตรวจครบ 2,753 แถวแล้ว min=max=0.74 A จึงเป็น constant-current discharge ไม่ใช่การเดาจากสองจุด

Qn เป็นพลังงานหรือไม่?

ไม่ใช่ Qn=2664 C=0.74 Ah เป็นประจุ พลังงานต้องคำนวณ ∫vi dt และมีหน่วย J หรือ Wh

ทำไมมี exponential สองเทอม?

เทอม +Aa exp(−Baq) สร้างส่วนโค้งเร็วช่วงต้น ส่วน −Ab exp[−Bb(Qn−q)] สร้างหัวเข่าช่วงท้าย

Ri ได้เท่าไร?

ตอบอย่างซื่อสัตย์ว่าแยก Ri จาก Eo ไม่ได้ในชุดนี้ ระบุได้เพียง Eo−0.74Ri ต้องมี current pulse หรือหลายระดับกระแส

ถ้าสมมติ Ri=0.2 Ω แล้ว Eo เท่าไร?

Eo=C₀+0.74Ri=4.184467052577080 V และต้องย้ำว่าเป็นค่ามีเงื่อนไข ไม่ใช่ Ri ที่ฟิตจากชุดเดิม

ทำไมไม่ใช้ L-BFGS-B เจ็ดตัวตรง ๆ?

ปัญหามี local minima, สเกลต่างกันมาก และ rank deficiency จึงใช้ variable projection + global rate search + bounded least squares ซึ่งมั่นคงกว่า

โมเดลแม่น 10⁻¹⁴ V แปลว่าดีในโลกจริงไหม?

ไม่จำเป็น ข้อมูลนี้แทบเป็นเส้นสังเคราะห์ไร้ noise ต้องตรวจ out-of-sample, temperature, hysteresis, aging และ sensor bias ก่อนใช้จริง

จะวัด Ri ใน EV/BESS อย่างไร?

ใช้ current pulse ที่ SOC และอุณหภูมิกำหนด ประมาณ Ri≈−Δv/Δi จาก voltage jump ก่อน dynamics ช้าเข้ามา แล้วทำซ้ำหลาย operating points
