## สามข้อค้นพบที่ทำให้ชุดนี้ต่างจากเฉลยชุดก่อนหน้า

### 1. เจอสาเหตุที่แท้จริงว่าทำไม $B_a$ สองค่าถึงไม่ตรงกัน

เฉลยชุดก่อน ([solution2](../solution2/GPT_SOLUTION.md)) เจอความไม่ลงรอยนี้เหมือนกัน แต่เขียนว่า *"สอดคล้องกันในทางอันดับมิติ"* แล้วสรุปว่า *"ทั้งสองวิธีตรงกันอย่างสมบูรณ์แบบ"* — **การพูดกลบตัวเลขที่ไม่ตรงกันแบบนี้คือสิ่งที่ทำให้ได้ 0 ในการสอบปากเปล่า**

สาเหตุจริงคือ: ในบรรทัดที่แก้หา $B_a$ ณ $t = 100$ s **เทอม $-K\cdot q(t)$ ถูกตัดทิ้งไป**

$$v(100) = E_o' \underbrace{- K(74)}_{\text{หายไป}} + A_a e^{-74B_a}$$

เทอมที่หายไปมีขนาด $2.724\times10^{-4} \times 74 = 20.2$ mV — เทียบกับแรงดันรวม 4 V คือแค่ 0.5% ดูเหมือนตัดทิ้งได้ **แต่เราไม่ได้เทียบกับ 4 V เราเทียบกับเทอมที่กำลังจะแก้หา ซึ่งมีขนาดแค่ 64 mV → คิดเป็น 31%**

ใส่เทอมกลับเข้าไป แก้ด้วยวิธีเดียวกันทุกประการ ได้ $B_a = 0.010248$ ตรงกับค่าคอมพิวเตอร์ที่ **0.1%** และ RMSE ดีขึ้นจาก 5.372 mV เหลือ 0.252 mV — **ดีขึ้น 21 เท่า**

หลักฐานปิดคดี: ค่าพลาดสูงสุดของชุดเดิมคือ **20.04 mV ที่ $t = 106$ s** เท่ากับขนาดของเทอมที่ตัดทิ้งพอดี และเกาะอยู่ตรงช่วงต้นเท่านั้น ไม่ได้กระจายทั่วทั้งชุด

> **วิธีพูดในห้องสอบ — ห้ามพูดว่า "อาจารย์คำนวณผิด"** สคริปต์เต็มอยู่ใน [คำถามที่ 7](CLAUDE_SOLUTION.md#คำถามที่-7-อันตรายสูงสุด-ค่า-b_a-ที่คุณฟิตได้-ไม่ตรงกับที่ผมคำนวณ-คุณคิดว่าใครผิด)

### 2. พารามิเตอร์ถูกออกแบบมาด้วยธรรมเนียม Shepherd/Tremblay

$$B_a \times Q_n = 27.272727\ldots = \tfrac{300}{11} \qquad B_b \times Q_n = 28.571428\ldots = \tfrac{200}{7}$$

เขียนใหม่ได้เป็น $B_a = 3/(0.110\,Q_n)$ และ $B_b = 3/(0.105\,Q_n)$ — **ทั้งคู่อยู่ในรูป $B = 3/Q_{\exp}$ พอดีเป๊ะ** ซึ่งเป็นธรรมเนียมมาตรฐานของแบบจำลอง Shepherd/Tremblay ใน MATLAB Simscape (ที่ $q = Q_{\exp}$ เทอมเลขชี้กำลังเหลือ $e^{-3} \approx 5\%$ = "ตายไป 95%")

ผู้ออกข้อสอบตั้งช่วงเลขชี้กำลังตอนต้นไว้ที่ **11.0%** และช่วงหน้าผาไว้ที่ **10.5%** ของความจุ

### 3. หน้าต่างเชิงเส้นมีขอบเขตที่คำนวณได้ ไม่ใช่ "ดูจากกราฟ"

ใช้เกณฑ์ว่าเทอมต้องเล็กกว่า 1 mV:

| เทอม | เงื่อนไข | ช่วงเวลา |
| :--- | :--- | :--- |
| $A_a e^{-B_a q}$ | $q > 481$ C | $t > 650$ s |
| $A_b e^{-B_b(Q_n-q)}$ | $q < 1{,}430$ C | $t < 1{,}932$ s |

**หน้าต่างเชิงเส้น = $q \in [481, 1430]$ C** และช่วงที่อาจารย์เลือกใช้ ($q = 740$ กับ $1{,}036$ C) อยู่กลางหน้าต่างพอดี — นี่คือคำตอบเวลากรรมการถามว่า *"ทำไมถึงเลือกช่วงนั้น"*

## เรื่องที่ต้องพูดให้ถูก: $E_o$ กับ $R_i$ แยกกันไม่ได้

เพราะกระแสคงที่ 0.74 A ตลอด เทอม $iR_i$ จึงเป็นค่าคงที่ มันรวมกับ $E_o$ เป็นก้อนเดียว ข้อมูลเห็นแค่

$$E_o - 0.74R_i = 4.036467\ \text{V}$$

คำตอบที่เป็นไปได้มีเป็นอนันต์ เรียงบนเส้น $E_o = 4.036467 + 0.74R_i$ · Jacobian มี rank = 1 ไม่ใช่ 2 ($\partial\hat v/\partial E_o = 1$, $\partial\hat v/\partial R_i = -0.74$ เป็นสัดส่วนกันทุกแถว) เรียกว่า **structural non-identifiability** ซึ่ง**แก้ไม่ได้ด้วยการเพิ่มข้อมูล**

ค่า $R_i = 0.0584\ \Omega$ ของอาจารย์มาจากการ**สมมติ**ว่า $E_o \approx v(100) = 4.0801$ V

> ❌ "ผม**คำนวณ** $R_i$ ได้ 0.0584 Ω" → ✅ "ผม**ประมาณ** $R_i$ ได้ 0.0584 Ω **ภายใต้สมมติฐานว่า $E_o \approx v(100)$**"
>
> ความต่างของสองประโยคนี้คือความต่างระหว่าง 60 คะแนนกับ 100 คะแนน

**ลองเห็นด้วยตา:** เปิดแดชบอร์ดแท็บ 6 → เปิดสวิตช์ 🔒 ล็อก $E_o'$ → ลาก $R_i$ จาก 0 ไป 2 Ω — **กราฟไม่ขยับแม้แต่พิกเซลเดียว RMSE คงที่** ทั้งที่ $R_i$ เปลี่ยนไป 34 เท่า

## ข้อมูลชุดนี้เป็นข้อมูลสังเคราะห์

การฟิตได้ RMSE $= 1.1\times10^{-13}$ V ซึ่งเป็นระดับ **machine epsilon** ของเลขทศนิยม 64 บิต เครื่องมือวัดจริงไม่มีทางละเอียดขนาดนี้แม้แต่ 1% — **ข้อมูลชุดนี้ถูกสร้างจากสมการเดียวกันนี้เอง** ถ้าเป็นข้อมูลแล็บจริง RMSE จะอยู่ราว $10^{-3}$–$10^{-2}$ V จาก noise, hysteresis, การเปลี่ยนอุณหภูมิ และ sensor bias

การสังเกตและพูดเรื่องนี้ในห้องสอบ แสดงว่านิสิตอ่านผลลัพธ์เป็น ไม่ใช่แค่รายงานตัวเลข
